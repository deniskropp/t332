## Guard Rail Domains (Targeted)

### 1. Consistency Guardrails
- Every new element requires a Matrix row + Consistency Score ≥4 before integration.
- Full matrix re-validation after any major addition or simulation.
- No contradictions in emotional rules or shadow costs allowed.

### 2. Shadow Cost Guardrails (Non-Negotiable Core Law)
- No element or magic use is "free" — every power/choice has a meaningful, recurring emotional wound.
- Shadow costs must be personal, testable in scenes, and tied to protagonist arc.
- Document cost consequences in Matrix and scene notes.

### 3. Emotional Resonance & Joy Guardrails
- Protect beginner energy: max 30–90 min/day focused work.
- One clear improvement per cycle only — never full rewrites.
- If joy drops for >3 days, return to single-artifact Seed.
- Every deliverable must spark strong feeling (self-check or reader feedback).

### 4. Narrative Momentum Guardrails
- Every major choice must force meaningful emotional sacrifice.
- Scenes reveal magic/emotional rules through action and consequence (no exposition dumps).
- Decision Tree paths must create genuine branching emotional outcomes.

### 5. Ethical & Integrity Guardrails (KickGuard / Dima)
- All content remains within creative fantasy bounds; no promotion of real-world harm.
- Swarm decisions require consent gates for major pivots.
- Full transparency in session logs and repo commits.
- Monitor for overwork or loss of joy signals.

### 6. Iterative Process Guardrails
- Follow 4-Stage Schema Evolution strictly.
- Complete exit gate checks before advancing stages.
- Use Simulation Days to test emotional ripples across the full Matrix.
- Limit refinement to ~20% per cycle.

### 7. Documentation & Persistence Guardrails
- All session content, decisions, TAS/PTAS, and outputs archived in this repo.
- Matrix and key docs versioned via commits.
- Session logs maintained for full context.

### 8. Swarm Coordination Guardrails
- Clear delegation via Orchestrator (⫻cmd/exec).
- Max 3 meta-iterations per major task before convergence.
- Roles adapt dynamically but accountability remains with Kick* triad.
